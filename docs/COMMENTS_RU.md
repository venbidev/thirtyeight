# Памятка редактора контента (RU)

Коротко и по делу: что и где менять, без тех‑деталей. Всё редактирование делается в файле `content.json`.

## 1) Цвета сайта (кнопки, ссылки, футер)
- Откройте `content.json` → раздел `colors`.
- Меняйте значения цветов в формате `#RRGGBB`:
  - `brand` — брендовый акцент
  - `primary` — основной цвет
  - `buttonBg` / `buttonHoverBg` — кнопка и наведение
  - `link` — ссылки
  - `footerBg` / `footerText` — фон и текст футера
  - `progress` / `progressTrack` — цвет прогресс‑бара

## 2) Тексты на странице
- Откройте `content.json` → раздел `textNodes`.
- Как найти нужный текст:
  1) Нажмите Поиск (Cmd+F) и введите видимую фразу на странице (например, «Why is this important?»).
  2) Нашли объект с нужным текстом? Меняйте значение в блоке `value` → нужный язык (`en`, `es`, и т.д.).
- Важно: не меняйте поля `selector` и `textIndex`. Меняйте только тексты внутри `value`.
- Если нужен русский:
  - Добавьте рядом ключ `"ru": "Ваш текст"`.
  - Чтобы по умолчанию показывался русский — см. раздел «Язык интерфейса» ниже.

Частые места (подсказки для поиска):
- Заголовок вверху: «Suspend Boris Johnson's taxpayer allowance»
- Подзаголовок «To: The Prime Minister…»
- «Petition text» (заголовок раздела)
- «Why is this important?» (подзаголовок)
- Основные абзацы начинаются с «Leaked files…», «And yet he’s still…», «From lobbying…», «Sign the petition now…»
- Кнопка «Help!»
- Футер: «38 Degrees», «| 2025», адрес, индекс

## 3) Ссылки (отписка/политика приватности и др.)
- Откройте `content.json` → раздел `linksDetailed`.
- Найдите нужный объект и поменяйте `href` на ваш URL.
- Оставьте `target: "_blank"`, если ссылка должна открываться в новой вкладке.
- Пример: заполните пустой `href` у пункта с текстом «privacy policy».

## 4) Цифры петиции (счётчик/цель)
- Откройте `content.json` → раздел `petition`.
- Меняйте числа:
  - `signed` — текущие подписи
  - `goal` — цель

## 5) Имена подписантов, которые «мигают»
- Откройте `content.json` → раздел `signer`.
- Меняйте список имён в `names`.
- Скорость смены имён — `intervalMs` (в миллисекундах), например `3000` = 3 секунды.

## 6) Тексты всплывающего окна «Поделиться»
- Откройте `content.json` → `overlay` → `textBySelector`.
- Найдите знакомые фразы (например, «Thanks for adding your name!») и замените текст на нужный язык.
- Сами ссылки для шаринга находятся в `overlay.linksBySelector`.
  - Обычно достаточно заменить в них конечный адрес страницы на ваш (внутри `href`).

## 7) Язык интерфейса (локализация)
- Откройте `content.json` → раздел `localization`.
- `defaultLocale` — язык по умолчанию (например, `"en"` или `"ru"`).
- Чтобы принудительно показать язык в браузере, можно открыть страницу с параметром, например `?lang=es`.
- Если добавляете новые переводы (например, `ru`), просто добавляйте ключ `"ru": "…"` в каждом нужном тексте (см. раздел «Тексты»).

## 8) Что НЕ трогать
- В `textNodes` не меняйте `selector` и `textIndex` — из‑за них находится место на странице.
- В `theme.js` ничего менять не нужно для обычного редактирования контента.

## 9) Как проверить изменения
- Откройте страницу в браузере (или обновите открытую вкладку).
- Если изменения не видны — обновите с очисткой кэша (Cmd+Shift+R).

Если нужно — могу пометить конкретные пункты в `content.json` под ваши тексты (чтобы их было проще находить) или добавить русский как язык по умолчанию.
